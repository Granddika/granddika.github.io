# Granddika portfolio

Статический сайт-портфолио на GitHub Pages: https://granddika.github.io/

## Как обновлять портфолио

1. Открыть https://granddika.github.io/admin/ (Sveltia CMS).
2. Нажать «Sign In with Token» и вставить свой GitHub-токен (fine-grained, доступ только к репозиторию granddika.github.io, Contents: Read and write).
3. «Портфолио» → «Работы». Добавить или изменить папку: «Обложка папки» — картинка на карточке, «Работы в папке» — файлы внутри.
4. Сохранить. GitHub Pages обновит сайт примерно за минуту.

Совет: несколько работ лучше добавлять за один заход и сохранять один раз.

## Хостинг

- GitHub Pages из ветки `main`, корень репозитория. Бесплатно, мягкий лимит трафика 100 ГБ/мес.
- Старый адрес granddika.netlify.app перенаправляет сюда (netlify.toml), сборки на Netlify отключены.

## Персональные данные

- Политика — `/privacy.html`. Формы сбора данных нет; кнопки связи открывают Telegram или почту.
